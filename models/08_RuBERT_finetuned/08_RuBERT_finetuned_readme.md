# Модель 08: RuBERT (finetuned) — полная нейросеть с дообучением
МОДЕЛЬ НАХОДИТС НА ЯНДЕКС ДИСКЕ https://disk.yandex.ru/d/VQAP0P2_ZJwg3w
## Описание
Восьмая и последняя модель для классификации тендеров на два класса:
- `supply` — поставка товаров
- `work` — выполнение работ или услуг

Это **полная нейросеть с дообучением**: текст подаётся напрямую в **RuBERT с классификационной головой**, которая была **дополнительно обучена** на наших данных.

**Ключевое отличие от модели 07:** RuBERT был **дообучен** на 11 523 размеченных тендерах (5 эпох).

---

## Что такое дообучение (finetuning)?

Дообучение — это процесс, при котором мы берём уже обученную нейросеть и продолжаем обучать её на наших данных.

| Без дообучения (07) | С дообучением (08) |
|---------------------|---------------------|
| Веса модели не меняются | Веса модели обновляются под нашу задачу |
| Модель знает только общий русский язык | Модель адаптируется под тендерную лексику |
| Время обучения: ~176 сек | Время дообучения: ~293 сек |

---

## Как работает модель
Текст → Токенизация → Дообученный RuBERT (12 слоёв) → Классификационная голова → Класс (supply/work)

### Шаг 1: Дообучение RuBERT
- Берём готовый RuBERT с классификационной головой (`num_labels=2`)
- Обучаем его на 11 523 размеченных тендерах (5 эпох)
- Модель адаптируется под тендерную лексику

### Шаг 2: Текст → токены
- Текст разбивается на токены
- Добавляются специальные токены: `[CLS]` (собирает смысл) и `[SEP]` (разделитель)

### Шаг 3: Токены → эмбеддинги → 12 слоёв Transformer
- Каждый токен превращается в вектор
- Эмбеддинги проходят через 12 слоёв Transformer
- На выходе — вектор `[CLS]`-токена, который кодирует смысл всего текста

### Шаг 4: Классификационная голова → класс
- Вектор `[CLS]` подаётся в слой классификации
- Слой вычисляет логиты для `work` и `supply`
- Логиты → `softmax` → вероятности → `argmax` → класс

---

## Почему дообучение не улучшило модель 08?

| Причина | Объяснение |
|---------|------------|
| **1. RuBERT уже сильный** | Базовый RuBERT обучен на миллиардах текстов и уже хорошо понимает русский язык |
| **2. Мало данных** | 11 523 примера — недостаточно для значимого дообучения |
| **3. Тексты короткие** | Названия тендеров не дают сложных контекстов для дообучения |
| **4. Переобучение** | Модель могла «запомнить» частные особенности датасета |
