# Модель 07: RuBERT (base) — полная нейросеть
МОДЕЛЬ ВО ССЫЛКЕ НА ЯНДЕКС ДИСКЕ https://disk.yandex.ru/d/Szfsg-2gqg0z4w
## Описание
Седьмая модель для классификации тендеров на два класса:
- `supply` — поставка товаров
- `work` — выполнение работ или услуг

Это **полная нейросеть**: текст подаётся напрямую в **RuBERT с классификационной головой**, которая сама превращает текст в эмбеддинги, обрабатывает их через 12 слоёв Transformer и выдаёт класс. 

**Ключевое отличие от предыдущих моделей (03–06):**
- В моделях 03–06 RuBERT использовался только для извлечения эмбеддингов, а классификатором была ML-модель (LogReg/CatBoost).
- В модели 07 **классификационная голова встроена в саму нейросеть** — вся модель обучается как единое целое.

---

## Как работает модель

### Шаг 1: Текст → токены
- Текст разбивается на токены (части слов)
- Добавляются специальные токены: `[CLS]` в начале, `[SEP]` в конце

### Шаг 2: Токены → эмбеддинги → 12 слоёв Transformer
- Каждый токен превращается в вектор (эмбеддинг)
- Эмбеддинги проходят через 12 слоёв Transformer
- На выходе — вектор `[CLS]`-токена, который кодирует смысл всего текста

### Шаг 3: Классификационная голова → класс
- Вектор `[CLS]` подаётся в слой классификации
- Слой вычисляет два числа (логиты): для `work` и для `supply`
- Логиты → `softmax` → вероятности → `argmax` → класс

**Важно:** Веса модели **не меняются** — используется готовая RuBERT от DeepPavlov «как есть».


### Что такое логиты?

Логиты — это два числа, которые выдаёт нейросеть перед принятием решения. Они показывают, насколько модель «думает», что текст относится к классу `work` или `supply`.

**Пример:**  
Текст: "Капитальный ремонт школы"  
Логиты: `[2.1, -1.3]` → модель уверена, что это `work`.

**Цепочка:**  
Логиты → softmax → вероятности → argmax → класс.

Логиты появляются только при использовании классификационной головы (модели 07–08).

## Почему модель 07 лучше гибридных моделей?

| Причина | Объяснение |
|---------|------------|
| **1. Полная нейросеть** | Вся модель обучается как единое целое, а не по частям |
| **2. Встроенная классификация** | Классификационная голова обучается вместе с эмбеддингами |
| **3. Больше возможностей** | Нейросеть может находить сложные зависимости |
| **4. Нет потери информации** | Эмбеддинги не усредняются (используется `[CLS]`-токен) |


### Что такое классификационная голова?

Классификационная голова — это дополнительный слой в RuBERT, который превращает смысл текста в класс (supply/work).

- В моделях 03–06 мы использовали **только эмбеддинги** (векторы), а классификацию делала ML-модель.
- В моделях 07–08 мы использовали **полную RuBERT с классификационной головой**, которая сама выдаёт класс.

### Классификационная голова

В моделях 03–06 мы использовали RuBERT **без классификационной головы** — только как генератор эмбеддингов.

В моделях 07–08 мы «включили» классификационную голову, загружая модель через `AutoModelForSequenceClassification` с параметром `num_labels=2`.

Это позволило модели самой выдавать класс, без отдельной ML-модели.


### Логиты, softmax, argmax

1. **Логиты** — два числа, которые даёт нейросеть (например, `[2.1, -1.3]`).
2. **Softmax** — превращает логиты в вероятности (например, `[0.89, 0.11]`).
3. **Argmax** — берёт класс с максимальной вероятностью (например, `work`).
