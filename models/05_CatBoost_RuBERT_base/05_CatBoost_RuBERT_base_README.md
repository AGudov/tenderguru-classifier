# Модель 05: CatBoost + RuBERT (base)

## Описание
Пятая модель для классификации тендеров на два класса:
- `supply` — поставка товаров
- `work` — выполнение работ или услуг

Это **гибридная модель**: текст сначала проходит через **нейросеть (RuBERT)**, которая превращает его в вектор чисел (эмбеддинг), а затем этот вектор подаётся в **CatBoost** (градиентный бустинг) для финальной классификации.

**Ключевое отличие от модели 03:** вместо логистической регрессии используется **CatBoost**, который способен находить более сложные зависимости.

---

## Как работает модель
Текст → RuBERT (768 чисел) → CatBoost → Класс (supply/work)

### Шаг 1: Текст → эмбеддинг (RuBERT)
- Текст разбивается на токены, проходит через 12 слоёв Transformer
- На выходе — вектор размером **768** чисел
- **Важно:** Веса RuBERT **не меняются** — модель используется «как есть»

### Шаг 2: Эмбеддинг → класс (CatBoost)
- Вектор из 768 чисел подаётся в CatBoost
- CatBoost строит множество деревьев решений
- На выходе — класс (`supply` или `work`) и уверенность

## Как считаются метрики

| Метрика | Формула | Что показывает |
|---------|---------|----------------|
| **Accuracy** | (TP+TN)/(TP+TN+FP+FN) | Доля правильных ответов |
| **Precision** | TP/(TP+FP) | Точность предсказаний `supply` |
| **Recall** | TP/(TP+FN) | Полнота — сколько реальных `supply` найдено |
| **F1‑Score** | 2*P*R/(P+R) | Баланс точности и полноты (главная метрика) |
| **ROC‑AUC** | Площадь под ROC‑кривой | Способность разделять классы |

## Сравнение с моделью 03 (LogReg + RuBERT base)

| Метрика | Модель 03 (LogReg) | Модель 05 (CatBoost) | Разница |
|---------|--------------------|----------------------|---------|
| Accuracy | 0.9779 | 0.9740 | **−0.0039** |
| Precision | 0.9865 | 0.9782 | **−0.0083** |
| Recall | 0.9775 | 0.9796 | **+0.0021** |
| F1‑Score | 0.9820 | 0.9789 | **−0.0031** |
| ROC‑AUC | 0.9972 | 0.9972 | **0.0000** |
| Время обучения | ~0.45 сек | ~13 сек | **+12.5 сек** |

**Вывод:**  
CatBoost на эмбеддингах RuBERT показал **результат хуже**, чем логистическая регрессия (F1 = 0.9789 против 0.9820). Это говорит о том, что эмбеддинги RuBERT уже хорошо разделяют классы, и линейная модель (LogReg) справляется с ними лучше, чем более сложный CatBoost.

---

## Почему CatBoost на эмбеддингах уступил LogReg?

| Причина | Объяснение |
|---------|------------|
| **1. Эмбеддинги уже линейно разделимы** | RuBERT создаёт векторы, которые хорошо разделяются одной прямой |
| **2. CatBoost переусложняет** | Деревья добавляют сложность там, где она не нужна |
| **3. CatBoost дольше обучается** | Требует больше времени без улучшения качества |
| **4. Меньше данных** | При небольшом количестве данных линейные модели часто работают лучше |
