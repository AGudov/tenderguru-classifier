# Модель 06: CatBoost + RuBERT (finetuned)

## Описание
Шестая модель для классификации тендеров на два класса:
- `supply` — поставка товаров
- `work` — выполнение работ или услуг

Это **гибридная модель с дообучением**: текст сначала проходит через **дообученный RuBERT**, который превращает его в вектор чисел (эмбеддинг), а затем этот вектор подаётся в **CatBoost** (градиентный бустинг) для финальной классификации.

**Ключевое отличие от модели 05:** RuBERT был **дополнительно обучен** на наших данных (11 523 размеченных тендера).

---

## Что такое дообучение (finetuning)?

Дообучение — это процесс, при котором мы берём уже обученную нейросеть (RuBERT) и продолжаем обучать её на наших данных.

| Без дообучения (05) | С дообучением (06) |
|---------------------|---------------------|
| RuBERT используется «как есть» | RuBERT дополнительно обучается на наших данных |
| Веса модели не меняются | Веса модели обновляются под нашу задачу |
| Модель знает только общий русский язык | Модель адаптируется под тендерную лексику |

---

## Как работает модель

Текст → Дообученный RuBERT (768 чисел) → CatBoost → Класс (supply/work)


### Шаг 1: Дообучение RuBERT
- Берём готовый RuBERT от DeepPavlov
- Обучаем его на 11 523 размеченных тендерах (5 эпох)
- Модель адаптируется под тендерную лексику

### Шаг 2: Текст → эмбеддинг
- Текст подаётся в дообученный RuBERT
- На выходе — вектор размером **768** чисел

### Шаг 3: Эмбеддинг → класс (CatBoost)
- Вектор из 768 чисел подаётся в CatBoost
- CatBoost строит множество деревьев решений
- На выходе — класс (`supply` или `work`) и уверенность

## Как считаются метрики

| Метрика | Формула | Что показывает |
|---------|---------|----------------|
| **Accuracy** | (TP+TN)/(TP+TN+FP+FN) | Доля правильных ответов |
| **Precision** | TP/(TP+FP) | Точность предсказаний `supply` |
| **Recall** | TP/(TP+FN) | Полнота — сколько реальных `supply` найдено |
| **F1‑Score** | 2*P*R/(P+R) | Баланс точности и полноты (главная метрика) |
| **ROC‑AUC** | Площадь под ROC‑кривой | Способность разделять классы |

---

## Почему дообучение и CatBoost не дали прироста?

| Причина | Объяснение |
|---------|------------|
| **1. Эмбеддинги уже линейно разделимы** | RuBERT создаёт векторы, которые хорошо разделяются одной прямой |
| **2. Дообучение не добавило информации** | 11 523 примера недостаточно для значимого улучшения |
| **3. CatBoost переусложняет** | Деревья добавляют сложность там, где она не нужна |
| **4. Линейная модель лучше** | На таких данных простая модель работает эффективнее |
